# unit tests

Mirrors the source tree. A unit test for `shared/python/gspipe/foo.py`
goes at `tests/unit/shared/python/gspipe/test_foo.py`. A unit test for
the Python side of `tools/rendering/3dsmax/python/bar.py` goes at
`tests/unit/tools/rendering/3dsmax/python/test_bar.py`.

Run with `pytest` from the repo root.
